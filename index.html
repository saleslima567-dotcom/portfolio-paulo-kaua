Plataforma de cursos

LearnPlay

Alunos podem encontrar cursos, retomar aulas de onde pararam e acompanhar o progresso. Professores têm um espaço para montar aulas e publicar cursos.

Usei o Flask para controlar o acesso por perfil e calcular o progresso a partir das aulas concluídas no banco.

React · TypeScript · Flask · PostgreSQL

Gestão de licenças

Inventário de Softwares

Cada conta tem sua própria lista de softwares. O painel mostra as licenças vencidas e as próximas renovações, e a lista pode ser exportada em CSV ou JSON.

Fiz a interface em JavaScript puro e usei Cloudflare Workers e D1 para guardar os registros de cada conta.

HTML · CSS · JavaScript · Cloudflare Workers · D1
